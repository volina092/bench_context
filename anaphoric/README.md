# anaphoric

Два варианта текста.

Вариант 1: модель 
- получает на вход
	- текст
	- подстроку (личное, возвратное, указательное или вопросительное местоимение), о которой ему надо сказать, какой сущности в тексте она кореферентна
	- три варианта ответа подстроки из этого текста (именные группы, не являющиеся анафорическими местоимениями)
- выдаёт 1 из трёх вариантов

В файле q0-anaphoric.json лежат пробные несколько вопросов

В папке /result лежат результаты испытаний для разных моделей (название файла совпадает с кодификатором модели)

Промпт формируется из словаря в формате, как в файле q-anaphoric.json (скрипты формирования промпта и запроса к модели лежат в файле Обращение к модели.ipynb)
