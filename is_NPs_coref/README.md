# is_NPs_coref

В этом тесте модель 
- получает на вход текст и две подстроки из этого текста (обе — именные группы, не являющиеся анафорическими местоимениями)
- отвечает на вопрос, кореферентны ли эти подстроки

В файле q1-is_NPs_coref.json лежат пробные несколько вопросов в формате:![изображение](https://github.com/user-attachments/assets/a627f71e-2307-4dd9-aae1-2e3fbb2d7156)

В папке /result лежат результаты испытаний для разных моделей (название файла совпадает с кодификатором модели)

Промпт формируется из словаря в формате, как в файле q1-is_NPs_coref.json (скрипты формирования промпта и запроса к модели лежат в файле Обращение к модели.ipynb)
